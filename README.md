# Sargent

**Sargent** is a chemical process simulator under development: sequential-modular flowsheet solving with
equation-oriented (Pyomo / IPOPT) optimization, Aspen Plus property-parameter import, electrolyte (eNRTL)
chemistry, and techno-economic and life cycle assessment (TEA / LCA) of the solved flowsheets, with a desktop
GUI and an AI assistant.

The first release is in preparation. This package and repository hold the project name until then; they contain
no simulator code yet.

Named in honor of Roger W. H. Sargent (1926-2018), founder of process systems engineering. Not affiliated with the
Sargent Centre for Process Systems Engineering (Imperial College London / UCL).
